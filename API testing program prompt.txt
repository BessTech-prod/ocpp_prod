Act as a Senior Full-Stack Developer. Your task is to build a modern, locally-hosted Web API Testing Tool specifically designed to interact with the TakoramaCharge CSMS and other generic REST APIs.

### Technical Requirements
1. **Tech Stack**: Use a modern framework of your choice (e.g., Python/FastAPI with Jinja2, Node.js/Express, or a simple React/Vue SPA).
2. **Core Functionality**:
    - Ability to send GET and POST requests.
    - Header and Query parameter management.
    - Response viewing with JSON syntax highlighting.
    - **Presets System**: A dropdown or sidebar to quickly load pre-defined configurations for specific endpoints.

### TakoramaCharge Specific Presets
Integrate the following presets for the TakoramaCharge system:

#### 1. External API v1 (Monitoring & Analytics)
- **Base URL**: `https://www.takoramacharge.se/api/v1`
- **Auth**: Query parameter `api_key` (Required).
- **Endpoint: Get Chargers**
  - Method: `GET`
  - Path: `/chargers`
  - Description: Returns a list of all chargers, their status, and lifetime metrics.
- **Endpoint: Get Energy Data**
  - Method: `GET`
  - Path: `/energy`
  - Required Params: `group_by` (Options: `user`, `charger`, or `connector`).
  - Optional Params: `period` (Options: `24h`, `1m`, `3m`, etc. - use `Xm` for X months), `org_id`.

#### 2. Command API (Remote Operations)
- **Endpoint**: `POST /api/portal/ocpp/command`
- **Headers**: Session-based auth (Cookies) or relevant authentication headers used by the portal.
- **Payload Structure**:
  ```json
  {
    "cp_id": "charger_id_here",
    "command": "command_name",
    "payload": {}
  }
  ```
- **Command Presets**:
  - `reset`: Payload: `{"type": "Soft"}` or `{"type": "Hard"}`.
  - `remote_start_transaction`: Payload: `{"idTag": "...", "connectorId": 1}`.
  - `remote_stop_transaction`: Payload: `{"transactionId": 123}`.
  - `unlock_connector`: Payload: `{"connectorId": 1}`.
  - `change_availability`: Payload: `{"connectorId": 1, "type": "Operative"}`.
  - `trigger_message`: Payload: `{"requestedMessage": "BootNotification"}`.
  - `get_configuration`: Payload: `{"key": ["HeartbeatInterval"]}`.
